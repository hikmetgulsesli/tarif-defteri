# PRD: Lezzet Defteri — Yemek Tarifi Defteri Uygulaması

## 1. Genel Bakış

**Proje Adı:** Lezzet Defteri
**Proje Slug:** tarif-defteri-6881400
**Platform:** Web (SPA — Single Page Application)
**Tech Stack:** React 18 + Vite + Tailwind CSS
**Dil:** Türkçe (tüm UI içeriği, kullanıcı metinleri, hata mesajları)
**Veritabanı:** Yok (tarayıcıda localStorage ile çalışır)

Lezzet Defteri, kullanıcıların yemek tariflerini kaydedebildiği, organize edebildiği ve favorilerine ekleyebildiği kişisel bir tarif defteri uygulamasıdır. Kullanıcılar yeni tarif ekleyebilir, malzeme listesi ve yapılış adımlarını kaydedebilir, kategorilere göre filtreleyebilir ve en sevdiği tarifleri favorilere alabilir.

**Hedef Kitle:** Ev aşçıları, yemek meraklıları, ailelerinin geleneksel tariflerini korumak isteyenler.

---

## 2. Hedefler

- Kullanıcıların tariflerini kolayca kaydetmesi ve geri bulması
- Kategorilere göre düzenli filtreleme yapabilme
- Malzeme listesi ve adım adım yapılış talimatları ile detaylı tarif profilleri
- Favori tariflerin hızlı erişilebilirliği
- Mobil uyumlu, dokunmatik dostu arayüz
- Hızlı yükleme ve akıcı sayfa geçişleri (<100ms)
- Tarayıcıda çalışan, kurulum gerektirmeyen uygulama
- Erişilebilir tasarım (WCAG 2.1 AA uyumlu)

## 4. Fonksiyonel Gereksinimler

### 4.1 Tarif Listeleme (Ana Sayfa)
- Tüm tarifler kartlı liste olarak gösterilir
- Her kartta: Tarif adı, kategori, küçük resim/thumbnail, favori durumu
- Kategori filtrelemesi (Navbar'da kategori dropdown)
- Arama kutusu ile ada göre arama (anlık, 2+ karakter sonrası)
- Boş durum: "Henüz tarif eklenmedi. İlk tarifinizi ekleyin!" mesajı
- Sıralama: Varsayılan (en yeni önce)

### 4.2 Yeni Tarif Ekleme
- Form alanları:
  - **Tarif Adı** (zorunlu, max 100 karakter)
  - **Kategori** (zorunlu, dropdown: Kahvaltılık, Öğle Yemeği, Akşam Yemeği, Tatlı, İçecek, Atıştırmalık, Çorba, Salata, Diğer)
  - **Malzeme Listesi** (dinamik ekle/sil, her biri malzeme adı + miktar)
  - **Yapılış Adımları** (dinamik ekle/sil, numbered list, her adım textarea)
  - **Notlar** (opsiyonel, textarea)
- Görsel yükleme: Base64 encoded image, max 2MB, JPG/PNG/WEBP
- Kaydet butonu: "Tarifi Kaydet"
- İptal: "İptal" butonu, onay gerektirmez
- Hata: "Lütfen tüm zorunlu alanları doldurun" (kırmızı, form üstünde)
- Başarı: Tarifler sayfasına yönlendir, toast: "Tarif başarıyla kaydedildi"

### 4.3 Tarif Detay Sayfası
- Üst kısım: Görsel (varsa), başlık, kategori badge
- Orta kısım: Malzeme listesi (checkbox ile işaretlenebilir)
- Alt kısım: Adım adım yapılış talimatları (numaralı liste)
- Notlar bölümü (varsa)
- Favori butonu: Kalp ikonu, dolu/boş durum
- Düzenle butonu: Detay sayfasından düzenleme formuna git
- Sil butonu: Onay dialogu sonrası silme, "Bu tarifi silmek istediğinizden emin misiniz? Bu işlem geri alınamaz."
- Geri butonu: Tariflere dön

### 4.4 Favoriler Sayfası
- Sadece favori olarak işaretlenen tarifler listelenir
- Aynı kart formatı (Tarif Listeleme ile)
- Boş durum: "Henüz favori tarifiniz yok. Sevdiğiniz tarifleri kalp ile işaretleyin!"
- Favori kaldırma: Kalp ikonuna tıklama ile kaldırılabilir

### 4.5 Arama ve Filtreleme
- Arama kutusu: Ana sayfada navbar'da
- Filtreleme: Kategori dropdown, "Tümü" seçeneği dahil
- Sonuç yok: "Arama kriterlerine uygun tarif bulunamadı"

## 5. Veri Modeli

### 5.1 Recipe Entity

```typescript
interface Recipe {
  id: string;                    // UUID, crypto.randomUUID()
  name: string;                  // Tarif adı
  category: CategoryEnum;        // Kategori
  image: string | null;          // Base64 string veya null
  ingredients: Ingredient[];     // Malzeme dizisi
  steps: string[];               // Yapılış adımları dizisi
  notes: string | null;          // Notlar (opsiyonel)
  isFavorite: boolean;           // Favori mi
  createdAt: string;             // ISO 8601 timestamp
  updatedAt: string;             // ISO 8601 timestamp
}

interface Ingredient {
  id: string;                    // UUID
  name: string;                  // Malzeme adı
  amount: string;                // Miktar (örn: "2 su bardağı", "500 gram")
}
```

### 5.2 Categories Enum

```typescript
type Category = 
  | 'kahvaltilik' 
  | 'ogle-yemegi' 
  | 'aksam-yemegi' 
  | 'tatli' 
  | 'icecek' 
  | 'atistirmalik' 
  | 'corba' 
  | 'salata' 
  | 'diger';
```

### 5.3 localStorage Schema

```
Key: 'lezzet-defteri-recipes'
Value: Recipe[] (JSON string)
```

## 7. Non-Functional Requirements

### 7.1 Performans

- **İlk Yükleme:** < 2 saniye (Lighthouse score > 90)
- **Bundle Size:** < 150KB gzipped (tüm JS)
- **Sayfa Geçişi:** < 100ms (React Router, no server round-trip)
- **localStorage Okuma:** < 50ms (küçük veri seti)
- **Image resize:** Client-side, 800px max genişlik

### 7.2 Erişilebilirlik (WCAG 2.1 AA)

- **Renk Kontrastı:**
  - Text: >= 4.5:1 (normal text)
  - Large text (18px+): >= 3:1
  - UI components: >= 3:1
- **Klavye Navigasyonu:**
  - Tab ile tüm interactive elementlere erişim
  - Enter/Space ile aktivasyon
  - Focus visible state (ring)
- **Ekran Okuyucu:**
  - ARIA labels tüm butonlarda ve form elemanlarında
  - Semantic HTML (nav, main, section, article)
  - Form error'ları aria-describedby ile bağlı
- **Touch Hedefleri:**
  - Minimum 44x44px tüm tıklanabilir alanlar

### 7.3 Tarayıcı Desteği

- **Desktop:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Mobil:** iOS Safari 14+, Android Chrome 90+
- **Responsive:** 320px (mobil) — 1920px (desktop)
